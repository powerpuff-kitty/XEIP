# Historical administrative capture

Status: local capture and complete-history validation verified; a dependency of complete organization recovery.

The existing owner journal records privileged binding labels, command digests, start/result summaries and unresolved attempts. A command digest cannot reconstruct omitted command content or authenticate a human operator. Recovery must preserve this evidence without executing it.

The filesystem-based [manual archive collector](../services/organization/cloudflare/ARCHIVE.md) already verifies complete administrative exports and optional prior witnesses. This format supplies internal Worker-compatible recovery capture and atomic incremental verification without importing filesystem/CLI code. It does not replace the manual archive format: that collector permits the live head to advance while completing an earlier cut, whereas these checkpoint pages require an unchanged head. Both use the original shared event/checksum validation rules.

`xeip.admin-checkpoint/1` binds organization, head sequence, head checksum and an artifact digest over all fields. An empty journal has sequence zero and the all-zero source predecessor. Original event checksums and source bytes remain unchanged. Hashes prove integrity, not provenance or freshness against whole-history rollback; independent journal/witness custody remains necessary.

`xeip.admin-history-page/1` binds the checkpoint digest, exclusive starting sequence, up to 16 original records, next sequence and a completion flag. Readers carry the previously verified checksum and request limit between pages. Reject gaps, forks, extras, short pages, incorrect completion, wrong scope and a final checksum different from the checkpoint. Pages are at most 64 KiB; events retain the existing 2 KiB limit and histories the existing 100,000-record ceiling.

The stateful verifier starts at genesis, enforces nondecreasing timestamps across page boundaries, rejects duplicate starts/results and terminal results without an earlier matching start, and preserves unresolved starts. Attempt matching covers operator, request ID, operation, command digest, attempt ID and before-state. Failed pages do not advance cursor, timestamps or attempt state. It retains a fixed-size digest/status per attempt rather than full event bodies, bounded by the source record ceiling. Finish requires all records through the pinned head; unresolved counts are evidence, not permission to retry.

Journal capture requires valid schema/history and stable organization metadata. Active attempts and pending synchronization conflict, even after a start has become locally durable. Reopening a valid journal permits capture of retained unresolved attempts. A changed head requires restarting capture; malformed requests do not quarantine usable state. Storage failures and corruption fail closed. Capture is synchronous and does not claim an independent durability receipt.

Source checkpoint/page capture retains the existing full-history validation, using bounded SQL reads. Repeated pages can rescan the retained history; bounded memory does not establish acceptable export CPU cost, startup time or throughput at the 100,000-record ceiling. Capacity/segmentation work must account for this before operational acceptance.

Implementation sequence: add native missing-feature regressions; extract unchanged audit record validators/checksums and implement the historical codec plus journal capture; expand multi-page/failure/cross-page tamper tests; obtain scoped review; run full local Cloudflare/root regression and affected pinned Node22/Linux tests plus strict types. Existing owner exports remain compatible. No schema migration, public/private-owner RPC, cloud deployment, deletion, command replay or restored-state activation is added.

Full recovery still requires one coordinated action/control cut, receipt-gated updates, current-journal reconciliation, complete fenced reconstruction, external execution fencing, credentials/Keycloak custody, accepted independent hosting and operator/security/workload acceptance.
